XENOVECTION — MAINLINE-CONVERGENCE-001
Native GPU visual synthesis · Draft/HOLD owner evaluator

RUN
Extract the complete folder and double-click Launch-Xenovection.cmd.
The application and its content are included; no Godot installation is needed.
Primary target: Windows 11, Vulkan-capable GPU (owner target: NVIDIA TITAN RTX).
Launch-Compatibility.cmd is an explicit OpenGL fallback for diagnosis.

TRY THIS FIRST
1. Start with Convergence. Orbit with the middle mouse button; zoom with wheel.
2. Choose Counterflow loom (2), move closer and watch the fine travelling strands.
3. Drag a box through source nodes. Click Knot, Ribbon or Membrane.
4. Open Optics and vary the environment, normal detail or geometric displacement.
5. Press G to inspect exact source topology without decorative effects.
6. Press G again, then U, to return that selected region to moving hairlines.

MODULAR SYNTH
F7 opens Synth. Recall one of six example patches; Perform opens the XY pad,
manual macros, envelope triggers, tempo and independent clocks. Patch opens the
source/route editor. Blank starts a new patch; New component, choose kind and
clock, Apply component, then New route, choose signal and searchable destination,
signed depth and offset, Apply route. Routes may be bypassed or soloed.
Save/Load uses a private user JSON slot; Import/Export opens a file chooser.
Morph loads the slot with a 0.8s transition only for identical scene/wiring.
Undo/Redo are patch edits; Ctrl+Z remains original selection undo.
Recall resets to the example scene. Stop or keys 1–7 return to baseline.
Patch edits restart graph phase/history. Pause freezes state; analytical clocks
can reverse but stateful delay, slew and walks do not reverse their history.
F5/F6 includes authored patch settings in scene snapshots, not runtime history.

CONTROLS
MMB: orbit. Shift+MMB: pan. Hold RMB: capture pointer and fly with WASD/QE.
Shift accelerates flight; Ctrl slows it. Release RMB or press Esc to release.
Click: exact source node/edge. Drag: through-depth source-region selection.
Shift adds to selection. F focuses selection. I isolates/reveals it.
M materialises a knot. U removes the proxy. Ctrl+Z / Ctrl+Shift+Z undo/redo visuals.
Space pauses all clocks; V reverses them. Clocks tab controls each separately.
R resets the preset. Keys 1–9 and 0 select the first ten presets; all thirteen are available in the picker. Tab hides the panel; H hides the HUD.
F5 saves scene; F6 recalls it. F9 exports exact selection. F10 exports metrics.
F12 captures the actual viewport. Exports are in %APPDATA%\Godot\app_userdata\Xenovection.

SOURCE AND ART
The default source is the exact recovered FOUND-001 synthetic 6×48 tanh specimen.
It contains 288 nodes and 11,520 stored coefficients. It is not an LLM.
Other density choices are explicitly new deterministic stress specimens.
Vortex atlas (7) uses the same adapter and renderer for a synthetic spatial field:
4,608 samples, 6,144 exact streamline/coupling edges. It is not measured fluid data.
Positions are a declared visual projection. Phase, secondary braids, optical
proxies and displacement are artistic. They never mutate source coefficients/IDs.
Scientific mode disables these decorative systems and retains exact inspection.
An optical ribbon budget may show a bounded sample of a selected region; the full
source membership remains in its selection receipt.

PERFORMANCE
The footer reports wall-frame percentiles, render CPU/GPU timing where supported,
draw calls and strands. F10 saves a fuller receipt. Profile-This-PC.cmd collects
a reproducible 600-frame Convergence profile after warm-up, requesting VSync off.
The engine log records any driver fallback to a synchronised presentation mode.
GPU timing on a software renderer measures that software device, not a TITAN RTX.
The build manifest identifies the precise source revision. Owner hardware and
subjective motion/visual acceptance remain separate from hosted qualification.

BUILD AND LICENSES

PROCEDURAL MATTER
Choose presets 08–13 in the header, open Matter. Select any of three region
slots, toggle visibility, edit placement, then focus (F) or isolate (I).
Condensation changes the actual gap between persistent strips; at 1 the strips
meet in a film. Shell wraps the same domain. Pores and growth change the film.
Flow mode integrates seeded fields on the CPU when topology is edited or when
Reintegrate is clicked. Strength, origin and mix animate the local GPU distortion
immediately; Reintegrate bakes them into flow geometry. Particles advance with
bounded positive filament-clock steps, pause on reverse; reset restarts them.
F5/F6 preserves region IDs, bases and baked field settings; history-dependent
particle positions restart, not a reversible simulation snapshot. Ctrl+Z undoes
region edits. G hides generated matter and exposes exact source data.

OPTICAL-003 — six additional editable optical studies, numbered 14–19.
Optics > Optical matter: mix 0 = accepted legacy appearance; mix 1 enables the optical model.
Thickness is authored in micrometres, not measured geometry; absorption is per micrometre.
Layer spacing creates one shared-mesh offset film. Refraction > 0 selects an opaque-background
screen-copy experiment; transparent strands and other films cannot appear in that copy.
Use the existing independent Sky, Palette, Normal and Displacement clocks. Diagnostic 1/2/3
shows estimated path, RGB transmission or Fresnel. Reset via preset; F5/F6 saves/recalls authored controls.
Use Forward+; the screen depth test is specifically reverse-Z Forward+.

ECOSYSTEM WORKSPACE
Run Launch-Ecosystem.cmd, or select Life > Open Ecosystem in the original instrument.
Six seeded ecosystems; choose the preset in the rail. Space pauses; Step advances
one 1/30 second tick. R resets to authored conditions. Set a seed before reset.
Select a tool, then click the ecology canvas to inspect, plant, place a resource
source/sink, or excite/inhibit the shared signal. Field view and quality do not
alter simulation. The interactions toggle disables consumption, deposits and
neighbor coupling, enabling paired comparisons. Reproduction is opt-in except
Terrarium. F5/F6 save/recall initial configurations, not simulation snapshots.
F10 exports a bounded trace to the application user-data folder. Tab hides the
rail. Escape returns to the source instrument (reloads its starting state).
Profile-Ecosystem.cmd collects a live Vortex Colony 600-frame profile.
Planar ecology is an artistic computational model, not a biological simulation.
The membrane perforation rings are a visual approximation, not optical holes.
