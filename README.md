# Xenovection

**Independent real-time visual synthesis, spatial exploration and interactive computational art.**

Xenovection is a home for GPU-native procedural visuals: ultra-fine animated filaments and filigree; wave-driven geometry and surfaces; responsive reflective and refractive materials; volumetric fields; modulation, continuous LUTs, and direct, game-like manipulation of complex data.

It is **not an LLM surgery engine**, nor is it restricted to neural-network visualisation. It must run compellingly on synthetic data or with no external data source. Neural-weight inspection, activation and perturbation overlays are optional *instrumentation adapters*, with computation and authoritative edits owned by separate tools such as [RustySpork Neurotzacken](https://github.com/techrote/rustyspork-neurotzacken).

**Programme state:** newly established repository; the architectural, artistic and prototype records are being prepared on a Draft PR. No renderer implementation or tested binary is claimed by this README.

Reference projects: [XenoField](https://github.com/techrote/XenoField), [PlasmaTerm](https://github.com/techrote/PlasmaTerm), [PlasmaTerm web](https://techrote.github.io/plasmaterm/web/). 

Design priorities: preserve thin-line/filigree rendering as a first-class art system; measure quality and frame time on real Windows hardware; distinguish measured data from visual metaphor; retain direct interaction; prefer small, useful experiments over CI-heavy process.

See the forthcoming docs design records and FOUND-series prototypes for the complete project history and implementation programme.
