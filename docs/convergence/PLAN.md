## Convergence decisions

One shared bus owns application targets/routes. A bounded 120 Hz scheduler resolves graph and typed routes; ecology samples after each four ticks at its original 30 Hz boundary. Field/growth rates remain 10/5 Hz. Rendering never writes numerical state.

Planar ecology remains available and shares persistent numerical state with a bounded spatial presentation. Switching workspaces must not reload the application or reset ecology. Optical mix zero preserves legacy behavior. Generated matter receives analytic optical parameters without taking topology ownership or enabling screen copies globally.

Presets retain legacy string IDs and gain namespaced stable IDs. Display order is seven original presets, six matter, six optical, then integrated compositions. Legacy numeric scene migration uses explicit lineage evidence; ambiguous saves are refused with an actionable message.

Composition saves describe authored state, not numerical history. Shared schema defaults never inherit unrelated live values. Source identity and all 11,568 binary64 specimen values remain exact.
